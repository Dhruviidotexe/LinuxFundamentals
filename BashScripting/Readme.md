Bash Scripting:
BASH- Bourne Again Shell is the default command-line shell for most linux distributions and macOS.
It allows user to execute commands, automate tasks, and combine commands into a single file called a script.

Why use bash script?
1. To automate repetitive system tasks
2. To run multiple commands together
3. To create system tools for administration or security
4. To schedule jobs (like backups, log cleanup, etc.)
